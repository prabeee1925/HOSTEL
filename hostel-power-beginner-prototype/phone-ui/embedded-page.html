Connect your phone to the ESP32 Wi-Fi to begin.

How this demo works: Your phone sends a command to the ESP32 over its own Wi-Fi network. The ESP32 changes the LED output or fan relay and sends the output state back to this page. All phones connected to this same ESP32 see the same room output state.

Prototype limit: ON/OFF here means the ESP32 output/relay command state. This beginner version does not measure actual electrical current and does not detect people in the room. Automatic occupancy cutoff, reminders, Firebase and the warden dashboard are saved for a later stage.
